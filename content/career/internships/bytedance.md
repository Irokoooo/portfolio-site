## AI 评测与模型反馈（AI Evaluation & Model Feedback）

### 中文

参与 Seed 旗下多模型的高价值 **Evaluation 题库建设**，作为执行负责人基于真实 bad case 持续迭代从题目验难、模型跑数到评测反馈的完整 Pipeline；独立 Vibe Coding 搭建 **Evaluation Workbench**，将完备性检查、AI 痕迹检测、高价值 / 场景筛选、Rubric、SOTA Response、3-Judge、Trace 分析与最终录用串联为可配置流程，并开发批量 Runner 模拟真实用户调用、获取豆包等参照模型 Response。支撑 **3,000 题目标量级**评测集生产及 **500 题级批处理 / 1,000 题级流式任务**，相关 Skill 人工抽检一致率由约 **50% 提升至 80%**，工作台已被 **3 个团队复用**。

同时参与不同 **Model × Agent × Harness** 配置下的模型能力实验，通过 A/B 实验、专家人评、偏序排名及 Bad Case / Trace 分析比较不同配置表现，沉淀模型能力反馈并支持后续配置迭代。

### English

Contributed to high-value **evaluation dataset development for multiple Seed models**, serving as an execution owner and iterating the end-to-end pipeline from question validation and model runs to evaluation feedback based on real production bad cases. Independently vibe-coded an **Evaluation Workbench** connecting completeness checks, AI-generated content detection, high-value and scenario screening, Rubric generation, SOTA responses, 3-Judge evaluation, Trace analysis, and final acceptance. Developed a batch Runner to simulate real user interactions and collect responses from reference models including **Doubao**. Supported a **3,000-question target-scale dataset**, **500-question batch runs / 1,000-question streaming workloads**, improved Skill spot-check agreement from approximately **50% to 80%**, and enabled reuse by **3 teams**.

Also participated in capability experiments across different **Model × Agent × Harness** configurations, combining A/B experiments, expert evaluation, partial-order ranking, and Bad Case / Trace analysis to compare behaviors and support configuration iteration.

## 内部工具与自动化（Internal Tools & Automation）

### 中文

从离线数据生产与质检中的高频重复操作出发，持续开发自动化工具与内部工作台，将典型项目配置流程由约 **120min 缩短至 23min**；独立开发飞书原生 QC 插件 **LightFlow**，服务约 **12 名内部 QC**，通过多 Response 对比、小语种翻译、附件同窗预览与任务导航，将单条质检耗时由约 **10min 降至 3–5min**，持续应用约 **1.5 个月、覆盖 2 期真实生产任务**。

### English

Built internal automation tools and workflow products for repetitive offline data production and QC tasks, reducing typical project setup from approximately **120 minutes to 23 minutes**. Independently developed **LightFlow**, a Feishu-native QC plugin used by around **12 internal reviewers**. Multi-response comparison, multilingual translation, in-panel attachment preview, and task navigation reduced review time per record from approximately **10 minutes to 3–5 minutes**. It was used for about **1.5 months across 2 production batches**.
