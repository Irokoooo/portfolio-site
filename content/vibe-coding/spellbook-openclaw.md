## 需求觉察（Motivation）

OpenClaw 具备强大的本地 Agent 能力，但传统终端交互对非技术用户并不友好：安装、命令、运行状态和历史任务都缺少直观反馈。我希望把这种能力装进一个更容易理解的工作台，让用户通过熟悉的网页聊天方式调度本地 Agent。

## 产品解法（Solution）

SpellBook 采用 Web 与本地 Agent 双端架构。网页端负责对话、任务管理与状态呈现，本地端负责实际执行，并通过离线任务队列和流式输出保持两端协同。

- 用对话界面替代主要 CLI 操作
- 可视化展示 Agent 状态、任务与输出过程
- 支持离线任务队列和恢复执行
- 面向 Windows 提供尽可能开箱即用的本地体验

## 技术实现（Implementation）

项目使用 Next.js、Supabase Realtime 与 Python FastAPI 串联网页和本地执行端，并围绕 Agent Architecture 处理任务分发、状态同步、流式消息和异常恢复。

## 迭代心得（Iteration Notes）

这个项目让我进一步确认：AI 产品的门槛不只来自模型能力，更来自交互方式和运行环境。把复杂能力变成普通人能理解、能观察、能恢复的工作流，本身就是产品设计最重要的一部分。
