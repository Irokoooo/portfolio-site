## 需求觉察（Motivation）

在“她来创造 · Coding Lady”女性 AI 创造者黑客松中，比赛以五种时间为共同命题。团队选择了**心流时间**：我们希望健康管理不再像一张不断催促人的待办清单，而是一段愿意主动进入、持续获得反馈的探索。

Zenow（之诺）因此被定义为一款 AI 健康陪伴游戏。用户完成现实中的健康任务，推动游戏中的角色掷骰前进、探索小镇、触发事件并积累成长，让行动、反馈与陪伴形成闭环。

## 痛点与挑战（Pain Points）

- 黑客松开发时间高度压缩，需要同时完成产品机制、视觉体验、前后端数据与可试玩版本。
- 健康任务容易滑向“打卡工具”，必须把外部激励转化为更自然的心流体验。
- 多条开发链路需要并行推进，但又不能互相覆盖代码或破坏已经可运行的版本。
- 现场路演前必须交付真实可访问、可操作的完整产品，而不只是概念演示。

## 落地解法（Implementation）

我负责 Zenow 的**全部技术落地**，并使用 Codex 与 Claude Code 组织了一套多 Agent 协作方式：由一个 Agent 作为中台拆解任务、管理边界和整合结果，多个 Agent 并行处理相互隔离的功能模块，在高压时间窗口内尽可能提高交付速度，同时避免代码冲突。

产品围绕“任务 → 掷骰 → 小镇移动 → 随机事件 / 奖励 → 成长反馈”搭建核心循环，并逐步加入 AI 小屋、每日运势、成长花瓣、技能卡与记忆星河等体验。技术上完成了交互式地图、3D 骰子、任务与奖励系统、Supabase 数据链路及移动端适配。

## 结果与验证（Outcome）

- 交付并正式部署可试玩版本：[zen0w.me](https://zen0w.me/?ui=20260725-2)
- 建立 **50+ 人试玩社群**，让产品在真实用户中持续获得反馈
- 获得黑客松**创意奖**
- 从现场 coding 到线下路演，完成了从概念、工程实现到公开展示的完整闭环

## 迭代心得（Iteration Notes）

这次实践让我验证了一件事：Agent 并行的价值不只是“写得更快”，更重要的是清晰的任务边界、统一的中台调度与持续集成。真正的效率来自让每条并行链路都知道自己负责什么、不能碰什么，以及何时回到主流程完成验证。

下一阶段会继续优化健康行为与游戏反馈之间的节奏，让成长不止是数值累计，而是更容易被感知、被记住的个人旅程。
